# ScooterCheck Premium Website

Vite + React + TypeScript Infoseite im ScooterCheck Corporate Design.

## Entwicklung

```bash
cd website
npm install
npm run dev
```

Öffne die angezeigte lokale URL (meist `http://localhost:5173`).

## Produktion

```bash
npm run build
npm run preview
```

## Assets

Originalgrafiken unter `public/assets/`:

- `scooter-cutout.webp` — freigestellter E-Scooter (aus App-Asset)
- `logo.webp` / `app-icon.webp` — Marke
- Radar wird per Canvas gezeichnet (nicht im Scooter-Bild enthalten)
